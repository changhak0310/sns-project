### 반영 내용
- `features/auth/hooks/use-login.ts`에서 `useSession()`을 연결해 로그인 성공 시 반환된 사용자 정보를 전역 session 상태에 저장하도록 수정했다.
- 같은 훅에 `submitLockRef`와 `stateRef`를 추가해 비동기 상태 갱신 구간이나 빠른 연속 클릭에서 중복 로그인 요청이 나가지 않도록 정리했다.
- 기존 명세의 `loginUser`, `formError`, `isLoading`, `resetLoginState()` 계약은 유지하면서 세션 연동을 최소 범위로 추가했다.

### 결과 또는 기대 효과
- 로그인 성공 시 전역에서 참조하는 현재 사용자 상태가 즉시 실제 로그인 사용자로 바뀐다.
- 버튼 연속 입력 상황에서도 같은 로그인 요청이 중복 전송될 가능성을 줄였다.

### 후속 이슈
- 현재 `SessionProvider`는 프리뷰 초기 사용자로 시작하므로 실제 서버 세션 복원은 후속 단계가 필요하다.
- 인증 성공 후 라우트 가드나 리다이렉트 연결은 별도 기능 단계에서 마무리해야 한다.
