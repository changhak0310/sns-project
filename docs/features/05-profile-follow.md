# 기능 05. 프로필과 팔로우

## 기능 목표

각 사용자에게 강한 정체성 화면과 아카이브 페이지를 제공해서, 서비스가 계속 쌓이는 제품처럼 느껴지게 만든다.

## 사용자 흐름

1. 사용자가 `/u/[username]`를 연다.
2. 아바타, 바이오, 통계, 게시물 그리드를 본다.
3. 그리드에서 게시물을 열거나 다른 사용자 프로필에서 팔로우를 누른다.

## UI 범위

- 프로필 헤더
- 아바타와 바이오
- 팔로워, 팔로잉 수치
- 팔로우 버튼
- 게시물 그리드

## 기능 구현

- 요약이 분명한 프로필 정보와 게시물 아카이브를 렌더링한다.
- 팔로우와 언팔로우를 지원한다.
- 프로필 페이지는 데모에서 보여주기 좋은 화면이므로 시각적으로 힘을 준다.

## 구현 로직

1. `app/(main)/u/[username]/page.tsx`가 서버에서 사용자와 해당 사용자의 게시물을 조회한다.
2. `lib/queries/profile.ts`는 프로필 요약, 그리드 게시물, 현재 사용자와의 관계 상태를 반환한다.
3. `components/profile/profile-header.tsx`가 정체성 정보를 렌더링한다.
4. `components/profile/profile-grid.tsx`는 각 게시물을 `/p/[postId]`로 연결된 타일로 렌더링한다.
5. `components/profile/follow-button.tsx`는 `lib/actions/profile.ts`를 쓰는 클라이언트 아일랜드다.
6. 팔로우 액션은 자기 자신을 팔로우하지 못하게 검증하고, 관계를 토글한 뒤 프로필 경로를 재검증한다.

## 상태관리

- 프로필 요약과 그리드: 서버
- 팔로우 상호작용: 로컬 낙관적 클라이언트 상태

## 필요한 데이터

- 사용자 프로필 필드
- 사용자 통계
- 게시물 그리드 아이템
- 현재 사용자의 팔로우 여부

## 완료 기준

- 게시물 작성자 링크에서 프로필로 이동할 수 있다.
- 팔로우 버튼이 현재 관계를 반영한다.
- 그리드에서 게시물 상세로 이동한다.
- 자기 프로필도 팔로우 없이 완성된 화면처럼 보인다.

## MVP 제외 범위

- 프로필 수정
- 태그된 게시물 탭
- 하이라이트
- 저장 컬렉션
- 보관함 제어
