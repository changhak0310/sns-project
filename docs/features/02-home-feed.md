# 기능 02. 홈 피드

## 기능 목표

팔로우한 사용자와 시드 추천 콘텐츠를 섞은 피드를 보여줘서, 서비스가 처음부터 살아 있는 느낌을 주게 한다.

## 사용자 흐름

1. 사용자가 `/`에 진입한다.
2. 피드에 최근 게시물이 렌더링된다.
3. 사용자는 카드 단위로 콘텐츠를 훑고 상세 페이지로 이동한다.
4. 카드에서 바로 좋아요를 누르거나 상세로 들어가 댓글을 남긴다.

## UI 범위

- 앱 헤더
- 피드 리스트
- 게시물 카드
- 캡션 미리보기
- 좋아요 수와 댓글 수
- 신규 계정용 빈 상태

## 기능 구현

- 세로 스택 구조의 피드를 렌더링한다.
- 작성자 아바타, 유저네임, 이미지, 캡션 미리보기, 메트릭을 보여준다.
- 이미지 전체 또는 상세 CTA가 `/p/[postId]`로 이동하게 한다.
- 카드에서도 빠른 좋아요 토글이 가능하게 한다.

## 구현 로직

1. `app/(main)/page.tsx`가 Server Component에서 피드 데이터를 조회한다.
2. `lib/queries/feed.ts`는 정규화된 피드 아이템 목록을 반환한다.
3. 초기 정렬 규칙은 단순하게 가져간다. 팔로우 중인 사용자의 최신 게시물 우선, 이후 시드 추천 게시물 순으로 배치한다.
4. `components/feed/feed-list.tsx`는 준비된 데이터를 받아 `post-card`로 매핑한다.
5. `components/feed/post-card.tsx`는 최대한 표현 위주 컴포넌트로 유지한다.
6. 좋아요 버튼만 `lib/actions/interaction.ts`를 쓰는 작은 클라이언트 아일랜드로 둔다.
7. 좋아요 이후에는 피드 경로를 재검증하거나 낙관적 업데이트를 적용한다.

## 상태관리

- 피드 목록 데이터: 서버
- 좋아요 상호작용 상태: 로컬 클라이언트 아일랜드
- 로딩 상태: 필요하면 route-level loading UI 추가

## 필요한 데이터

- 게시물 이미지
- 작성자 요약 정보
- 캡션 미리보기
- 좋아요 수, 댓글 수
- 현재 로그인 사용자의 좋아요 여부

## 완료 기준

- 피드가 안정적인 이미지 레이아웃으로 렌더링된다.
- 카드가 모바일 기준으로도 완성돼 보인다.
- 게시물을 누르면 상세로 이동한다.
- 좋아요 상호작용이 분명하게 갱신된다.
- 빈 피드 상태가 존재한다.

## MVP 제외 범위

- 무한 스크롤
- 스토리 스트립
- 탐색 랭킹
- 영상 게시물
